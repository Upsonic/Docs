## Constructor Parameters

| Parameter | Type | Default | Description |
|-----------|------|---------|-------------|
| `session_id` | `str` | (required) | Unique identifier for this chat session. Realigned to `agent.memory.session_id` if the agent's memory already carries one (emits `UserWarning`). |
| `user_id` | `str` | (required) | Unique identifier for the user. Realigned to `agent.memory.user_id` if the agent's memory already carries one (emits `UserWarning`). |
| `agent` | `Agent` | (required) | The Agent instance to handle conversations |
| `storage` | `Storage` | `None` | Storage backend. **Agent-first policy**: only used when `agent.memory` is `None`. Otherwise the agent's existing storage wins and this kwarg is ignored. |
| `full_session_memory` | `bool` | `True` | Store full conversation history. Ignored when the agent already has memory (the agent's memory config wins). |
| `summary_memory` | `bool` | `False` | Enable conversation summarization. Ignored when the agent already has memory. |
| `user_analysis_memory` | `bool` | `False` | Enable user profile analysis. Ignored when the agent already has memory. |
| `user_profile_schema` | `type` | `None` | Custom Pydantic schema for user profiles. Ignored when the agent already has memory. |
| `dynamic_user_profile` | `bool` | `False` | Auto-generate profile schema. Ignored when the agent already has memory. |
| `num_last_messages` | `int` | `None` | Limit history to last N messages. Ignored when the agent already has memory. |
| `feed_tool_call_results` | `bool` | `False` | Include tool calls in memory. Ignored when the agent already has memory. |
| `user_memory_mode` | `'update' \| 'replace'` | `'update'` | How to update user profiles. Ignored when the agent already has memory. |
| `debug` | `bool` | `False` | Enable debug logging |
| `debug_level` | `int` | `1` | Debug verbosity (1=standard, 2=detailed) |
| `max_concurrent_invocations` | `int` | `1` | Maximum concurrent invoke calls |

<Note>
**Agent-first resolution.** When `agent.memory` is already wired (either because
the agent was built with `memory=…`, `storage=…`, `db=…`, or because the agent
class — like `AutonomousAgent` — seeds a default memory), `Chat` reuses it as-is:
`storage` and every memory-config kwarg above are silently ignored. To configure
those features, pass them when building the agent's `Memory`, not on `Chat`.
</Note>

## Instance Properties

| Property | Type | Description |
|----------|------|-------------|
| `state` | `SessionState` | Current session state (IDLE, AWAITING_RESPONSE, STREAMING, ERROR) |
| `all_messages` | `List[ChatMessage]` | All messages in the session |
| `usage` | `AggregatedUsage` | Read-only view over every model call recorded for this session — tokens, cost, requests, tool calls, timing. See [Metrics](/concepts/chat/metrics). |
| `start_time` | `float` | Session start time (Unix timestamp) |
| `end_time` | `float` | Session end time (None if active) |
| `duration` | `float` | Wall-clock session duration in seconds |
| `last_activity` | `float` | Time since last activity in seconds |
| `is_closed` | `bool` | Whether the session is closed |

## Example

```python
import asyncio
from upsonic import Agent, Chat


async def main():
    agent = Agent("anthropic/claude-sonnet-4-5")

    chat = Chat(
        session_id="session1",
        user_id="user1",
        agent=agent,
        full_session_memory=True,
        summary_memory=True,
        num_last_messages=50,
    )

    response = await chat.invoke("Hello!")
    print(response)

    print(f"State: {chat.state.value}")
    if chat.usage.cost is not None:
        print(f"Cost: ${chat.usage.cost:.4f}")
    print(f"Tokens: {chat.usage.total_tokens}")


if __name__ == "__main__":
    asyncio.run(main())
```
