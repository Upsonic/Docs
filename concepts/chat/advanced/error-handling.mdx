## Retry Configuration

Retries are configured on the underlying `Agent`. `Chat` has no retry
knobs of its own — it delegates entirely to `Agent.do_async`'s
`@retryable` behavior. Set `retry=N` on the `Agent` to control the
total number of attempts:

```python
import asyncio
from upsonic import Agent, Chat


async def main():
    agent = Agent("anthropic/claude-sonnet-4-5", retry=5)

    chat = Chat(
        session_id="session1",
        user_id="user1",
        agent=agent,
    )

    response = await chat.invoke("Hello")
    print(response)


if __name__ == "__main__":
    asyncio.run(main())
```


## Error State Recovery

Check and recover from error states:

```python
import asyncio
from upsonic import Agent, Chat


async def main():
    agent = Agent("anthropic/claude-sonnet-4-5")
    chat = Chat(session_id="session1", user_id="user1", agent=agent)

    print(f"State: {chat.state.value}")

    try:
        response = await chat.invoke("Hello")
        print(response)
    except RuntimeError as e:
        if "error state" in str(e):
            chat.reset_session()
            print("Session reset")


if __name__ == "__main__":
    asyncio.run(main())
```

## Concurrent Invocation Limits

Control maximum concurrent requests:

```python
import asyncio
from upsonic import Agent, Chat


async def main():
    agent = Agent("anthropic/claude-sonnet-4-5")

    chat = Chat(
        session_id="session1",
        user_id="user1",
        agent=agent,
        max_concurrent_invocations=2
    )

    tasks = [
        chat.invoke("Question 1"),
        chat.invoke("Question 2")
    ]

    responses = await asyncio.gather(*tasks)
    for r in responses:
        print(r[:50] + "...")


if __name__ == "__main__":
    asyncio.run(main())
```
